# שירים דומים – אפליקציה לאנדרואיד

אפליקציה שמופיעה בתפריט **שיתוף** של יוטיוב. משתפים אליה שיר ומקבלים:
שירים דומים, עוד שירים של אותו אמן, שירים מאותו ז'אנר ומיקס של יוטיוב.
לחיצה על שיר פותחת אותו באפליקציית יוטיוב.

## שלב 1: העלאה לאינטרנט (פעם אחת, מהמחשב, בחינם)

1. נכנסים ל-[github.com](https://github.com) ופותחים חשבון אם אין.
2. לוחצים **New repository**, נותנים שם (למשל `similar-songs`), בוחרים **Public** ולוחצים **Create repository**.
3. לוחצים על הקישור **uploading an existing file**, גוררים פנימה את **כל הקבצים** שבתיקייה הזו ולוחצים **Commit changes**.
4. נכנסים ל-**Settings** ← **Pages**. תחת **Branch** בוחרים `main` ולוחצים **Save**.
5. אחרי דקה-שתיים האפליקציה זמינה בכתובת:
   `https://<שם-המשתמש>.github.io/similar-songs/`

## שלב 2: התקנה בטלפון

1. פותחים את הכתובת בטלפון בדפדפן **Chrome**.
2. לוחצים על כפתור **התקנה** באפליקציה, או בתפריט של כרום (⋮) בוחרים **הוספה למסך הבית** ← **התקנה**.

## שימוש

באפליקציית יוטיוב לוחצים **שיתוף** ← **שירים דומים**.
אפשר גם לפתוח את האפליקציה ישירות ולהדביק קישור, או לכתוב "אמן - שיר".

## עדכון

כדי לעדכן, מעלים את הקבצים החדשים לאותו מאגר ב-GitHub. האפליקציה בטלפון מתעדכנת לבד.
